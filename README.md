Sou desenvolvedor júnior e trabalho no ERP Oracle da AgRoss Insumos com **PL/SQL** e **integração de sistemas**: consulto dados de produção para verificar se a regra de negócio está sendo aplicada e implemento a correção.

### No que eu trabalho

- 🔎 **Auditoria de dados de produção** — acho a regra de negócio que não está sendo aplicada, meço o efeito e proponho o ajuste
- 🗄️ **Oracle PL/SQL** — procedures, functions, triggers e views; SQL analítico em vários schemas e SQL dinâmico
- 🧾 **ERP e fiscal** — NF-e, SEFAZ, CFOP, CST, condição de pagamento e alçada
- 🔌 **Integração** — APIs REST, Web Services, webhooks e Meta WhatsApp Business API
- 🤖 **IA aplicada** — agentes sobre as APIs da Anthropic e da DeepSeek, com a ação irreversível travada no código, não no prompt
- 🧭 **Liderança técnica** — montei a esteira de deploy e os guias do time, e criei as ferramentas que a equipe usa para entender o ERP
