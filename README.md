Trabalho com TI e desenvolvo sistemas internos: back-end em **PHP + Oracle**, dashboards de dados e automações com **IA**.

### O que faço hoje

- 🗄️ **Back-end e banco** — PHP integrado direto ao Oracle, com procedures, functions e views em PL/SQL
- 📊 **Dados** — dashboards e relatórios gerenciais em cima do ERP
- 🤖 **IA aplicada** — agentes de IA dentro dos sistemas e atendimento pelo WhatsApp Cloud API
- ⚙️ **Automação** — rotinas de TI automatizadas com scripts e Claude Code
